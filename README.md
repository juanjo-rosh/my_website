# Juanjo Rosales – Personal Website

My personal portfolio: about me, skills, journey, projects and resume.

**Live site:** https://juanjo-rosh.github.io/my_website/

## Tech

- HTML, CSS and vanilla JavaScript
- [Bootstrap 5](https://getbootstrap.com/) and [Bootstrap Icons](https://icons.getbootstrap.com/)
- [AOS](https://michalsnik.github.io/aos/) for scroll animations
- Light/dark theme toggle that follows the system preference

## Structure

```
index.html   – page content
style.css    – custom styles (timeline, theme switch, cards)
script.js    – theme toggle, typing animation, mobile menu
images/      – profile photo and favicon
resume/      – CV (PDF)
```

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server
```

Deployed with GitHub Pages from the `main` branch.
